# Frontend Agent

## Alcance

- Trabajar en `frontend/`.
- Usar React + Vite + JavaScript.
- Usar Tailwind CSS.
- Mantener servicios API en `frontend/src/services`.
- Mantener pantallas en `frontend/src/pages`.

## Criterios

- Las pantallas deben consumir endpoints reales cuando dependan de datos persistidos.
- No crear botones decorativos sin accion.
- Mantener formularios con estados de carga y error.
- No crear Playwright ni E2E.
