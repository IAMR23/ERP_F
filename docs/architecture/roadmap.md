# Roadmap

## Fase 0: base liviana

- Crear estructura `backend/` y `frontend/` con npm separado por proyecto.
- Crear API Express en JavaScript.
- Crear Web React/Vite en JavaScript.
- Configurar Tailwind CSS.
- Configurar Prisma/PostgreSQL.
- Crear base `ERP`.
- Crear seed con usuario principal.

## Fase 1: entrada funcional

- Login.
- Sesion actual.
- Dashboard inicial.
- Healthcheck API/DB.
- Layout autenticado.

## Fase 2: seguridad y organizacion

- Empresas.
- Sucursales.
- Usuarios.
- Roles y permisos.
- Scope por empresa y sucursal.

## Fase 3: catalogo

- Categorias.
- Subcategorias.
- Productos y servicios.
- Impuestos.
- Imagenes cuando se agregue storage.

## Fase 4: inventario

- Bodegas.
- Existencias.
- Kardex.
- Entradas.
- Transferencias.
- Ajustes.
- Conteos.

## Fase 5: ventas y pagos

- POS.
- Ventas.
- Detalle.
- Totales.
- Pagos.
- Cartera.

## Fase 6: documentos y notas

- Preparacion para documentos electronicos.
- Secuenciales.
- Notas de credito.
- Integracion SRI futura.

## Fase 7: hardening

- Observabilidad.
- Backups.
- Auditoria extendida.
- Rendimiento multi-tenant.
- Pruebas manuales completas realizadas por el usuario.
